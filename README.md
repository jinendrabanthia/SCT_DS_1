# SkillCraft Technology Data Science Internship - Task 1

## Overview
This repository contains the completion of Task 1 (SCT_DS_1) for the SkillCraft Technology Data Science internship. 

The goal of this task is to create a bar chart or histogram to visualize the distribution of a categorical variable against a continuous variable.

## Description
This project visualizes the top 10 most populous countries in the world for the year 2024. The data was processed and visualized using Python.

### Features
- **Data Source**: 2024 population estimates for the top 10 countries.
- **Conversion**: The raw data (provided in thousands) is converted to millions for better readability on the chart's axis.
- **Visualization**: A modern, clean horizontal bar chart built using `seaborn` and `matplotlib`.

## Tools Used
- **Python**
- **Pandas** (for data structuring)
- **Matplotlib** & **Seaborn** (for visualization)

## Output
The script generates an image file named `population_bar_chart.png` in the project root.
