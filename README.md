## 📝 Project Overview

This repository contains the completion of **Task 1** for the **SkillCraft Technology Data Science Internship**. 

The primary objective of this task was to create a bar chart or histogram to visualize the distribution of a categorical variable against a continuous variable.

---

## 🎯 Task Details

- **Categorical Variable:** Country
- **Continuous Variable:** Population (in Millions)
- **Data Source:** 2024 population estimates for the top 10 most populous countries.

### ✨ Key Features
- **Data Transformation:** Raw population numbers (provided in thousands) were mathematically converted to millions to ensure clean, readable chart axes.
- **Modern Visualization:** Leveraged the `viridis` color palette in Seaborn for a striking, modern aesthetic.
- **Data Labels:** Engineered the chart to display exact population values directly on each bar for maximum clarity.
